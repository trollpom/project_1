# Муж на час — демонстрационный проект для портфолио

Современная обезличенная версия лендинга из `https://github.com/trollpom/project_1.git`.

## Структура

```text
dist/
  index.html             Страница и контент
  styles.css             Дизайн, адаптивная сетка и анимации
  app.js                 Меню, калькулятор, диалог и демоформы
  assets/
    master.webp          Сгенерированный портрет
    work.webp            Сгенерированная рабочая сцена
    favicon.svg          Иконка сайта
    sans.woff            Локальный шрифт Noto Sans
    sans-bold.woff       Noto Sans Bold
    serif-italic.woff     Noto Serif Italic
    FONT-LICENSES.txt    Лицензионные сведения из шрифтов
image-prompts.md          Промпты фотографий
```

Сайт статический. Установка Node.js, зависимостей и сборка не нужны. Для хостинга используется содержимое `dist/`. В архиве для переноса эти файлы расположены сразу в корне, поэтому `index.html` можно открыть в браузере.

## Что изменено

- Новая тёплая палитра: лесной зелёный, светлый кремовый и терракота.
- Крупные заголовки, курсивные акценты, фотографии и векторные иконки.
- Все исходные фотографии удалены из поставляемых файлов; новые фотографии созданы встроенным генератором изображений.
- Реальное имя мастера заменено вымышленным персонажем Никитой. Аватары отзывов заменены буквенными иконками.
- Убраны фиктивные телефонные и мессенджерные ссылки, бизнес-разметка и неподтверждённые рейтинги. Отзывы явно отмечены как иллюстративные.
- Сохранены шесть направлений услуг и стартовые цены из исходника. Добавлен выбор работ с предварительной суммой и переносом списка в заявку.
- Анимации появления, состояния кнопок и карточек, мобильное меню, диалог заявки, FAQ. При `prefers-reduced-motion` анимации выключаются.
- Формы проверяют заполнение и номер телефона, затем показывают результат демонстрации. Никаких заявок, запросов к серверу, аналитики, cookies или сохранения введённых данных.
- Шрифты находятся в проекте: внешние сервисы шрифтов не нужны.

## Публикация из GitHub или Netlify

Перенесите содержимое `dist/` в корень репозитория. **Удалите старую папку `assets` перед заменой**: иначе старые фотографии могут оставаться доступными по прямым URL, даже если новый HTML их не использует.

Для Netlify можно загрузить папку с `index.html` вручную. При публикации из репозитория команда сборки не нужна, каталог публикации — корень проекта, если файлы `dist/` перенесены туда; иначе `dist`.

Оригинальный репозиторий GitHub не обновлён автоматически. Поставляемый архив не содержит `.git` или исходных фотографий. История исходного репозитория по-прежнему может содержать прежние фото: новая версия сайта сама по себе не удаляет историю Git.

## Проверка

Проверены синтаксис JavaScript, уникальность ID, локальные ссылки и файлы, SVG-иконки, подписи полей, адаптивные правила и отсутствие оригинальных изображений в поставляемой версии. Выполнены проверки логики калькулятора, выбора услуги, открытия/закрытия диалога, мобильного меню и демоформ в изолированной модели DOM.

Полноценная визуальная проверка в браузере в текущей среде недоступна. Перед рекламным запуском откройте страницу на телефоне и компьютере.

Это демонстрационная версия. Чтобы собирать реальные заявки, нужно отдельно подключить обработчик формы, актуальные контакты и условия услуги.
